# Security policy

Ferrastra, QPane, and CuteCanvas receive security fixes on their latest
published release lines. Upgrade to the latest available version before
reporting a vulnerability that may already be resolved.

## Reporting a vulnerability

Report suspected vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/Artificial-Sweetener/CuteCanvas/security/advisories/new).
Include the affected product and version, reproduction conditions, expected
impact, and any proof-of-concept material that can be shared safely.

Do not open a public issue, pull request, or discussion for an undisclosed
vulnerability. The maintainers will use the private advisory to validate the
report, coordinate a fix, and arrange disclosure.

## Scope

Security reports are especially useful for unsafe native behavior, untrusted
document or package input, path traversal, arbitrary code execution, dependency
confusion, publication integrity, secret exposure, and denial-of-service paths
that cross the products' documented resource bounds.
